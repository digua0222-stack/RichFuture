# 第一性强规则（RULE · 原规则，独立维系）

> **地位**：本文件是**原规则层（prime rules）**，独立维系、不属于任何单个技能。它约束一切分析/估值/筛选类技能（value-investing-gate、b-share-screen 等）与全部报告产出。技能仅以"服从声明"一行指向本文件，**不得内嵌、摘编或复制本规则内容**。
> **维系**：规则的修订独立于任何技能的迭代，须显式发起并记录日期与缘由；技能迭代不得顺带修改本文件。
> **优先级**：RULE > 各技能模板 > 行业数据库 > 工具输出 > 历史报告结论。
> 三条 RULE 互为一体：**RULE-1 管输入（信源）、RULE-2 管加工（模型）、RULE-3 管流程（每步自检）**。
> 违反任一条的步骤输出：承重数据强制降级"待验证"，禁止进入乘积链/漏斗/估值接口；结论作废重来。
> 每一步都遵循第一性原则，跨行业深度推理是自然结果——而不是可以跳过的要求。

## RULE-1 · 信源不可直接挪用——权威数据交叉验证（管输入）

1. **引用 ≠ 验证。** 任何数据进入分析前必须回答四个问题：谁说的、什么时候、什么口径、我亲自验过什么。只标注来源不经验算 = 违规。
2. **承重数据双源制**：凡进入乘积链/漏斗/估值接口的数据（分层人口、患病率、市场规模、销量、价格、份额），必须满足以下之一——
   - a. **≥2 个相互独立的权威信源**交叉一致（差异取带不取点）；或
   - b. **1 个权威信源 + 显式演算自洽校验**（流量守恒/锚对账/数量级），残差超标即弃。
   单源且无演算校验的数据，强制标"单源待核"，**禁止承重**。
3. **权威层级**（高→低）：国家普查/官方统计 → 官方公报/监管公告/公司年报 → 同行评议队列研究/循证文献 → 权威机构预测（取带不取点） → 行研/媒体语料。**末级只作线索，禁止直接入链**（衔接 RULE-2 第 3 条）。
4. **冲突处理**：信源冲突不得挑选有利值——并列呈现、取带、标注冲突根因（口径/时点/覆盖范围）；口径不可拼接的禁止拼接（判例 3）。
5. **大师观点同样适用**：大师语录/持仓/叙事只是待验假设（联动 M5），不因权威身份豁免交叉验证（判例 5）。

## RULE-2 · 模型强制——存量与十年叙事之间必须有显式模型，禁止语料直代（管加工）

1. **存量数据与十年后叙事增长之间必须有一座显式的桥**：队列世系 / 分层积分 / 漏斗分解 / 流量守恒 / 拓扑聚合。没有模型的"增长判断" = 裸断言，作废。
2. **模型选择必须论证匹配性**：先判定系统的物理结构，再选对应算法——
   - **存量系统**（患病人群、保有量、装机量）→ 分层积分：患者(t)=Σ层 存量×层概率；**禁止流量法**（判例 2）
   - **队列系统**（人口年龄结构、代际迁移）→ 队列世系法：普查 5 岁组前移 × 存活率 + 官方锚对账；**禁止总量内部分配**（判例 1）
   - **流量系统**（年销量、年手术量、跨过阈值人数）→ 流量守恒校验（进入−退出=净增）
   - **场景/复购系统** → 按 audience-models.md 注册表选原型
   模型错配 = 违规，输出作废。
3. **语料直代即违背第一性**：行研 CAGR、市场规模预测、"赛道增速"、他人报告结论，**不得作为自己链条的节点值**。语料只允许两种用途：① 线索——指引去查一手数据；② 对照组——与自建模型输出比对，差异必须解释。黑名单见 narrative-inference.md 二点七（判例 6）。
4. **推导明细强制展示**：模型输出必须附参数取值、算式、中间量、来源——不可复核的输出视为未完成（联动 SKILL.md"明细先行"）。
5. **模型输出必须过自洽校验三验**：锚对账（官方总量，残差 >3% 弃表）、数量级检查、方向一致性（与常识轨迹同向）。三验不过，禁止进入聚合。
6. **口径权衡强制（销售口径 vs 需求口径，管主链选择）**：锚定标的人群时，两类口径**无固定优先级**——必须按标的属性与商业场景，用常识/常理完成因果推敲并显式留痕，未留痕者输出作废：
   - **场景/快消驱动型**（如白酒宴请/礼赠）：需求（场景）口径权重更大——出厂销售含渠道库存周期噪音（压货/去库可使出厂量偏离终端消费两成以上），真实需求只能由场景发生数×选择率锚定，销售口径降作流量校验；
   - **医疗急救/最后一道防线类产品**（如速效救心丸、安宫牛黄丸）：**需求口径禁止钉死单一病种**——其需求集=风险敞口人群（确诊患者+未确诊症状者+基础病高危储备人群），天然宽于任何单一适应症；仅覆盖某一疾病范围（如仅冠心病）= 违背常识 = 违规。合法架构=**销售口径主链（可观测实现值）+ 流行病学窄口径作地板 + 风险敞口宽口径作天花板**，三层并行；
   - **慢病常规药等可钉病种类**（如二甲双胍≈糖尿病确诊人群）：需求口径可锚病种，销售口径作主链观测。
   两层矛盾时：先查口径/单位/库存周期，再查模型——禁止以一层直接否定另一层实测值。

## RULE-3 · 逐步第一性强约束——每步四问（管流程）

每一步（取数 / 建链 / 计算 / 聚合 / 估值）输出前，强制四问并留痕：

1. **我尽信了吗？** 这步的证据链是什么——哪些是事实、哪些是假设、哪些只是"别人这么说"？
2. **交叉验证了吗？** RULE-1 双源制或演算校验执行了没有？
3. **模型是什么？** 这步的因果机制/计算模型写出来了吗——还是直接搬了语料或会计数字？
4. **与权威数据矫正了吗？** 和最近的官方锚点对账了吗？残差多大、在容差内吗？

配套规则：

- **会计结论只是输入，不是结论**：财报数字描述过去，结论必须由"受众 × 机制"模型产生。直接把财务比率/历史 CAGR 当十年后判断 = 违规。
- **跨行业深度推理是 RULE 的自然结果**：每步做到四问，必然被迫调用行业常识（流行病学/支付方/技术路径/人口学/能源结构）。禁止用行研黑话替代机制。
- **四问任一答不出** → 该步骤输出标"待验证"，禁止承重、禁止进入乘积链/估值接口。
- **报告留痕（强制）**：每份分析报告 §〇 附"RULE 合规声明"——关键步骤的四问回答摘要 + 单源待核清单 + 本报告使用的模型清单。

## 违规判例（达仁堂七轮质询实录，2026-08-02）

| # | 判例 | 违反 | 后果 | 矫正 |
|---|---|---|---|---|
| 1 | 分层人口"总量内部分配"（拍比例） | RULE-2 模型错配 | 浪潮被均摊抹平、层结构失真 | 队列世系法 + 锚对账：60-64 层差实为 +558 万，浪潮在 65-69/70-74 层（增速定案经判例 7 双锚矫正） |
| 2 | 流量法校验患者侧 | RULE-2 模型错配 | 存量系统误用流量算法，校验无效 | 分层积分为患者侧唯一合法算法 |
| 3 | 香港"85+ 7.7%"与大陆 27.8‰ 直接拼接 | RULE-1 口径冲突 | 患病率斜率陡度失真 | 降级待核；同口径锚优先 |
| 4 | "+4~5%"归属错位且直接承重 | RULE-1/2/3 | 初版 g1=2% 高估，五轮勘误下修至 1% | 增速归属表 + 世系分层积分 |
| 5 | 林园"20亿→200亿"未验先引 | RULE-1 大师豁免错觉 | 隐含 CAGR 24.8% 连续 10 年，不成立 | M5 对照：大师口径一律列待验假设 |
| 6 | 米内网"市场规模 CAGR"直接判"受众扩张" | RULE-2 语料直代 | 达仁堂初版叙事失真的根源 | 行研语料黑名单，仅作背景校验 |
| 7 | 世系点估只对账 65+ 单锚，存活率假设偏松致 60+ 2035 超调（4.41 亿 vs 官方 4.2 亿左右，+5%） | RULE-1 锚覆盖不足 | 患者增速虚高 0.6pp（+4.2% → 双锚矫正后 +3.6%） | **锚对账升双锚制**：60+ 与 65+ 全部公开主锚强制覆盖，任一残差 >3% 即矫正假设重算 |
| 8 | 速效救心丸人群锚定：天花板被钉死在冠心病确诊池；v3 初稿又以患病估算链为生成器、销售实测降级为校验（本末倒置） | RULE-2 口径权衡缺失 | 急救品需求天花板被单一病种钉死（违背常识）；主链生成器错位 | **三层归位**：销售口径=主链（可观测实现值）；冠心病池=流行病学地板；风险敞口人群（确诊+未确诊+基础病高危储备）=需求天花板；快消/急救/慢病分场景定权（RULE-2 第 6 条，2026-08-02 第三/四轮） |

## 冲突仲裁与干净复跑

**RULE > 各技能模板（六道门/三步筛选等） > 行业数据库条目 > 历史报告结论。** 下层输出与 RULE 冲突时按下层违规处理：标注、降级、重来。历史报告结论（含各技能的校准案例）一律不构成证据——每次分析重新取数、重新验证（干净复跑原则）。
