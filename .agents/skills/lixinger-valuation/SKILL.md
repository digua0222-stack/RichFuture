# 理杏仁估值（lixinger-valuation）

只回答一个问题：**比自己历史贵还是便宜**。三层分工：**financial-facts=质量层**（报表真不真）→ **lixinger-valuation=位置层**（本技能，比自己历史贵不贵）→ **value-investing-gate=预测层**（未来值多少）。本技能产出是位置事实，不是投资指令。

> 服从声明：本技能执行时服从独立维系的原规则 [rules/RULES.md](../../../rules/RULES.md)（元规则 META-1~4 / RULE-1 / RULE-2 / RULE-3）。规则不内嵌；冲突时 RULE 优先。
> 方法论底座（权威补齐，必读）：[references/methodology.md](references/methodology.md)——分位点官方定义、口径变体、聚合四法、负值处理、禁区。

## 铁律（不预测）——四条

1. **区间标注=机械相对位置**：低估区/高估区只表示"相对自身历史的位置"，**禁止写成"会涨/会跌/买入/卖出/目标价"**；理杏仁官方立场同为"历史统计结果，仅供参考"。
2. **遍历性承重假设显式标注**：每份输出必须写明"历史分布代表未来分布"是本方法的承重假设——结构变化时分位失真（methodology 第六节）。
3. **单一指标禁止承重**：PE/PB/PS/PCF 分位两两背离 >50pp 时，必须先查明谁被污染（移交 financial-facts），再出具结论。
4. **口径先行**：扣非/不扣非、含/不含商誉、TTM/LF、数据源——未标口径的分位数字作废；跨数据源禁止直接比数。

## 工作流（四步）

1. **取数**：脚本直连东方财富估值明细接口（日频，2018 至今，point-in-time 口径）：
   ```bash
   python .agents/skills/lixinger-valuation/scripts/lx_valuation.py --code <code> \
     [--dividend-ttm <近12个月分红总额>] [--lo 20 --hi 80] --out data/derived/<code>_valuation_lx.json
   ```
   分红总额从 `data/snapshots/<code>.json` 的 `dividends_declared_fy` 取；接口不可达时改用 iFinD 插件，**禁止凭记忆填数**。
2. **分位计算**：3Y/5Y/10Y/全部四窗口；分位点=低于当前值的取样点占比（理杏仁官方定义）；序列剔除 ≤0 与缺失（中证口径）。
3. **区间与背离判读**：默认 <20% 低估区 / >80% 高估区（社区另有 30/70 宽松档，可用参数切换并标注）；检查脚本红旗（PE↔PS、PE↔PB 背离、PEG 负值、PE≤0）。
4. **出具位置诊断**：结构=当前值表（含口径）→ 四窗口分位表 → 区间判定 → 背离归因（若有）→ 承重假设与禁区声明。

## 输出契约

- 文件：`reports/YYYY-MM-DD_<code>_估值位置诊断_kimi.md`
- 每表标注：数据源 / 口径 / 窗口 / 阈值；结论三级标注沿用 financial-facts 的**事实/算术延伸/待验证**。
- 温度（如引用）必须标注"社区复合，非理杏仁官方"。
- §〇 RULE 合规声明（RULE-3 强制）。
- 组合/指数估值：聚合四法（市值加权/等权/正数等权/中位数）公式见 methodology 第三节；脚本当前仅支持单标的，组合模式待建——不得用单标的脚本冒充组合口径。

## 实证锚（达仁堂 600329.SH，as of 2026-07-31）

PE-TTM 13.52 → 10Y 分位 **12.25%（低估区）**；但 PS-TTM 5.92 → **91.88%（高估区）**、PCF_OCF_TTM → 82.45%（高估区）、PB 3.92 → 77.94%（中性偏上）——**PE↔PS 背离 79.6pp 红旗成立**：利润端被 2025 年 13.08 亿一次性处置收益压低 PE，营收端同步暴露"便宜的 E 是被污染的 E"。温度 45.09（社区复合）。股息率 TTM 6.11%（18.02 亿分红/294.9 亿市值；快照口径注：分红由一次性收益支撑）。PEG_CAR=-5.15 失真禁用。结论形态示范："四指标分位背离、PE 分位单独不可承重，利润质量判读移交 financial-facts"——无一句未来判断。
