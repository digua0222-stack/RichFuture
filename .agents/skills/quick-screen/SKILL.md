# quick-screen — 四维参数化快速筛选

> **服从声明**：本技能无条件服从 `../../../rules/RULES.md`（META-1~4 元规则 + RULE-1/2/3）。凡本文件与 RULES 冲突，以 RULES 为准。

## 定位（体系四层分工）

| 层 | 技能 | 职责 |
|---|---|---|
| **筛选层（本技能）** | `quick-screen` | 四维阈值机械过滤，产出候选池 |
| 筛选层（专用） | `b-share-screen` | B股三步叙事模板（早期专用版，保留） |
| 质量层 | `financial-facts` | 候选标的财务事实与红旗 |
| 位置层 | `lixinger-valuation` | 估值分位与温度 |
| 预测层 | `value-investing-gate` | 十年叙事+估值 gate |

本技能输出**仅**为候选池。通过 ≠ 值得买；剔除 ≠ 否定。通过名单中的异常值（如净利率>100%、股息率异常高）不做修正，原样呈现并交由质量层复核。

## 四维指标（全部参数化，默认值即昨日B股策略）

| 维度 | 参数 | 默认 | 数据口径 |
|---|---|---|---|
| 净利率% ≥ | `--min-jll` | 10 | 东财 F10 年报主指标 XSJLL |
| 负债率% ≤ | `--max-zcfzl` | 50 | 东财 F10 年报主指标 ZCFZL |
| 每股经营现金流(元) > | `--min-ocf` | 0 | 东财 F10 年报主指标 MGJYXJJE |
| 股息率% ≥ | `--min-dy` | 3 | 目标财年宣告每10股派息合计(人民币)÷10÷人民币折算最新价 |

## 市场与领域参数

- `--market`：`all / b / b-sh / b-sz / a / a-sh / a-sz / kcb / cyb / bj`（默认 `b`）
- `--board 中药`：行业板块名**包含匹配**（东财 BOARD_NAME，如"中药"命中"中药Ⅱ"）；仅 A股通道有效，B股无板块字段，传入会 WARN 并忽略
- `--years 2023,2024,2025`：默认最近完整财年单年；多年则要求逐年达标，最新年达标但早年破线者入**边缘名单**

## 工作流

```bash
# B股四维默认（昨日策略的复现与泛化）
python3 scripts/quick_screen.py --market b --years 2025

# A股某行业板块，自定义阈值
python3 scripts/quick_screen.py --market a --board 中药 --min-dy 2

# 全市场严格档
python3 scripts/quick_screen.py --market a --min-jll 15 --max-zcfzl 40 --min-ocf 0 --min-dy 4 --years 2023,2024,2025

# 结果落文件
python3 scripts/quick_screen.py --market b --out ../../reports/快速筛选_B股_kimi.md
```

执行后：读剔除清单抽查 2~3 只验证过滤逻辑符合预期，再把通过名单交给用户选择深研标的。

## 数据源与已知边界（RULE-1：如实标注）

- **A股**：东财 `RPT_VALUEANALYSIS_DET`（最新交易日全量：市值/PE_TTM/PB_MRQ/板块/收盘价）+ `RPT_F10_FINANCE_MAINFINADATA`（年报）+ `RPT_SHAREBONUS_DET`（分红）
- **B股**：东财估值明细接口**不覆盖B股** → 清单走新浪 hs_b、最新价走新浪批量行情；分红东财未覆盖者走新浪分红页 fallback（公告月<8归上财年）
- **币种**：沪B报价美元、深B报价港币，分红宣告人民币 → 股息率按新浪即期汇率（USDCNY/HKDCNY）折算，接口失败回退常量并 WARN
- B股无板块/市值/PE/PB 字段，输出显"—"
- 股息率为近似 TTM（预案未除权亦计入；股本变动期有近似误差）
- 接口不可达时退出码 2，不编造数据（RULE-1）

## 输出契约

1. Markdown 三清单：**通过名单**（按股息率降序）/ **边缘名单**（最新年达标、早年破线，标注破线财年）/ **剔除清单**（含剔除原因，供复查）
2. 头部标注：市场/板块、财年、阈值、扫描数→通过/边缘/剔除数
3. 尾部口径注记 + 纪律声明：本清单为机械阈值过滤的候选池，不含贵贱/未来判断
