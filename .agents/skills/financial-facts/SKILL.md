# 财务事实分析（financial-facts）

只回答"过去与现在是什么"，不回答"未来会怎样"。三层分工：**b-share-screen=筛选层**（候选池）→ **financial-facts=事实层**（本技能，数据体检）→ **value-investing-gate=预测/估值层**（十年叙事与门禁）。本技能可独立使用，也可作 gate 的前置事实清洗层——把事实搞干净，再谈叙事。

> 服从声明：本技能执行时服从独立维系的原规则 [rules/RULES.md](../../../rules/RULES.md)（元规则 META-1~4 / RULE-1 信源交叉验证 / RULE-2 模型强制 / RULE-3 逐步四问）。规则不内嵌于本技能；冲突时 RULE 优先。

## 铁律（不预测）——五禁止一允许

1. **禁止外推任何斜率/增速**——"近三年 CAGR"只能陈述，禁止暗示未来；
2. **禁止叙事词**——赛道、空间、护城河强弱、管理层评价，一律不出现在诊断书；
3. **禁止估值结论与贵贱判断**——目标价、"低估/高估"、"应该值多少"全部禁止（现状快照只陈述位置）；
4. **禁止补拍缺失数据**——缺字段进 missing_fields，缺模块整体标 null；
5. **禁止叙事归因**——离群年份的归因必须有公告/附注实据，找不到标"待验证"；
6. **允许的唯一外推形态=算术延伸**，且必须显式标注。判定法：**删掉时间维后等式仍成立=算术延伸**（如 股息率=已宣告分红÷现价、杜邦三分乘积）；一旦含"将/会/延续"=预测，禁止。

## 工作流（六步，顺序固定）

1. **取数**：优先 `data/raw/<code>_em_{is,bs,cf,main}.json` 快照；无快照则从东方财富 F10/年报原文双源取数（RULE-1 双源制），记录 as_of 与口径。快照采集见 `tools/update_snapshot_drt.py`（达仁堂样例）。
2. **勾稽守恒校验（数学先行）**：BS 恒等式、现金守恒（残差≈汇率项，≤期末现金 0.5% 为自洽）、收现比/净现比。**数据不自洽先停**——查口径/单位/并表范围，禁止带着残差分析。
3. **跑脚本**：
   ```bash
   python .agents/skills/financial-facts/scripts/fin_facts.py --code <code> \
     [--snapshot data/snapshots/<code>.json] --out data/derived/<code>_facts.json
   ```
4. **逐模块判读**：对照 [references/fact-modules.md](references/fact-modules.md) 的解读规则与红旗阈值逐模块下判断——脚本只算，判断由分析者完成并留痕（META-2）。
5. **离群归因**：M7 离群年份必须给事实归因（年报附注/公告）；找不到标"待验证"。
6. **现状快照**：搬运 PE/PB/市值/股息率披露值与历史分位（如有），只陈述位置，不评贵贱。

## 输出契约（事实诊断书）

- 文件：`reports/YYYY-MM-DD_<code>_财务事实诊断_kimi.md`
- 每节标注**数据期间 / 来源 / 口径**；结论三级标注：
  - **事实**（披露值或其守恒校验）
  - **算术延伸**（纯代数关系，必须给公式）
  - **待验证**（缺数据或归因未实，禁止承重）
- 红旗清单独立成节：每条=指标+阈值+期间+事实描述；**禁止写"意味着未来会…"**
- §〇 附 RULE 合规声明（RULE-3 强制）：四问摘要+单源待核清单+本报告使用的模型清单

## 模块导航（详见 references/fact-modules.md）

| 模块 | 内容 | 核心红旗 |
|---|---|---|
| M1 勾稽守恒 | BS/现金恒等式、收现比、净现比 | 净现比连续<0.8；收现比<1 |
| M2 盈利质量 | 应计率、投资收益依赖、扣非/归母、核心利润率 | 投资收益>利润总额 20%；扣非/归母<0.8 |
| M3 资产质量 | 商誉、应收/存货、在建/固定、存贷双高 | 商誉>净资产 10%；存贷双高 |
| M4 资本回报 | ROE 披露值、杜邦三分、ROIC | 杜邦乘积与披露值背离 |
| M5 股东回报 | 分红/融资对账（现金流口径+宣告口径） | 分红靠一次性收益/融资支撑 |
| M6 现金流画像 | 经营/投资/筹资八型 | 全吸型、休克型 |
| M7 离群 YoY | 收入/净利/经营现金突变 | 突变无附注实据=待验证 |
| M8 现状快照 | PE/PB/市值/股息率披露值搬运 | 只陈述、零判断 |

## 实证锚（达仁堂 600329.SH，2026-08-02 首跑）

净现比 2024-2025 连续 <0.8（0.42/0.22，去库存+联营收益为权益法非现金）；投资收益占利润总额 66-74%（2024-2025，联营中美史克）；扣非/归母 0.33-0.37（非经常项含史克处置收益 13.08 亿）；画像 2024"扩张失血"→2025"奶牛"；ROIC≈29%（2025，含处置收益）；宣告分红 18.02 亿=归母 84.56%（快照口径注：一次性收益支撑）。全部为事实级陈述，无一句预测。
