# B股潜力筛选

从全市场 B 股中筛出"盈利质量尚可 + 杠杆安全 + 真分红"的候选池。B 股是边缘市场：流动性差、外资撤退、长期折价，**折价是常态而非错误**——本筛选的目的不是"找会涨的"，而是"在折价池里找现金流真实、愿意分钱的公司"，为深度估值提供候选。

## 范围与口径（M1，先钉死）

- **范围**：仅 B 股。深市 `200xxx.SZ`（港币报价）、沪市 `900xxx.SH`（美元报价）。A+B 同股同权，B 股为外币报价的人民币资产（红利以人民币宣告、折外币支付）。
- **价格币种**：深 B → HKD，沪 B → USD；折人民币需当日汇率（HKDCNY / USDCNY）。**任何跨市场比价必须先折算，禁止直接比数字**。
- **财务口径**：净利率用年报销售净利率（东财字段 XSJLL，归母口径会失真时改用扣非并标注）；负债率用资产负债率（ZCFZL）；分红按 FY 宣告口径（含中期+年度+特别分红），区别于现金流量表支付口径。
- **财年窗口**：近 3 个完整财年（如 2023/2024/2025）。中报、季报不用于判定，仅用于边际信号。

## 三步过滤（顺序固定）

| 步 | 指标 | 阈值 | 数据源 |
|---|---|---|---|
| 1 | 销售净利率（各年度年报） | **<10% 不予通过** | 东方财富 RPT_F10_FINANCE_MAINFINADATA（XSJLL） |
| 2 | 资产负债率 | **>50% 不予通过** | 同上（ZCFZL） |
| 3 | 分红 | **近 3 个财年连续有现金分红**（含中期/年度/特别），缺任一财年即淘汰 | 东财 F10 分红融资接口、公司公告 |

- 三步按顺序执行；第 1 步即淘汰最多的标的（B 股大量为低毛利贸易/制造业）。
- **边缘规则**：近 3 年中有年份破线（如某年净利率 <10%）但最新年报达标 → 归入"边缘候选 ⚠️"，必须标注波动事实并建议人工复核，不得与确定通过者混列。
- 破线但分红达标的标的列入剔除清单 A（财务不达标）；分红不达标的列入剔除清单 B——**两张清单都要留档**，便于下轮复查（如苏威孚B 2025 净利率 9.15% 属擦线剔除，可能次年回转）。

## 执行

```bash
python .agents/skills/b-share-screen/scripts/b_share_screen.py
```

脚本从东方财富公开接口拉取全部 B 股的 XSJLL/ZCFZL 与分红记录，输出三步筛选表（Markdown）。接口不可达时，改用 iFinD 插件或联网搜索逐只核验，**禁止凭记忆填数**。

### 数据源实测要点（2026-08 验证）

- **B 股清单**：新浪 `hs_b` 节点（GBK，按 `trade>0` 剔退市/停牌，约 78 只）；东财 push2 行情接口对 urllib 指纹不稳定，仅作备选。
- **财务（净利率/负债率）**：东财 `RPT_F10_FINANCE_MAINFINADATA`，按报告期**批量**拉全市场（`REPORT_TYPE="年报"`），本地筛 B 股代码——**该接口对并发敏感，>1 线程易 400，必须串行**；filter 中字符串用双引号、日期用单引号。
- **分红**：东财 `RPT_SHAREBONUS_DET` 按 `NOTICE_DATE` 范围批量拉（约 36 页/3 年），**A+B 公司分红记录挂在 A 股代码下，纯 B 股（如伊泰B 900948，B+H 结构）不收录**；未命中标的 fallback 新浪分红配股页 `vISSUE_ShareBonus/stockid/<code>.phtml`（pandas.read_html 解析）。
- **财年归属**（新浪口径）：以**公告月**为准——公告月 ≤7 归上一财年（年度/前三季度分红），≥8 归当财年（中期分红）；已宣告未除息的同样计入（如粤高速B 2025 年度分红 2026-08 才除息）。
- 输出含"最新财年分红方案"列；脚本判定与人工报告可能有个位数标的差异（口径与覆盖差异），以脚本为准并在报告注明口径。

## 输出格式（照此模板，存 reports/B股三步筛选_<日期>.md）

1. **通过名单**：标的 | 代码 | 行业 | 净利率 3 年 | 负债率 3 年 | 分红 3 年 | 股息率（最新年度每股分红 ÷ 现价，外币报价先折本币再算，注明汇率）| 判定（✅通过 / ⚠️边缘）
2. **剔除清单 A**（分红达标但财务不达标）：逐项写明破线指标与数值
3. **剔除清单 B**（分红不达标）：写明断分红财年
4. **结论**：确定通过 N 只 + 边缘 N 只

## 衔接：筛选 → 六道门

- 本筛选**只是候选池，不构成买入依据**。通过标的有估值需求时，启动 `value-investing-gate`（六道门）做第一性深度剖析——硬指标远比三步严格（ROE 5 年 ≥15%、OCF/净利 ≥80%、营收/扣非连续 3 年增长等），历史上古井贡 B 通过三步筛选后被六道门 REJECT@GATE1。
- 周期类标的（煤炭、航运、化工，如伊泰B）通过筛选后尤其注意：净利率高点即周期高点，六道门第 2.5/2.6 道须用周期中值盈利而非最新年，禁止线性外推。

## 已知陷阱

- **股息率幻觉**：行情软件 TTM 股息率会把中期+年度+特别分红全部累进 12 个月窗口，高估常态化水平；须按 FY 宣告口径自行计算。
- **断分红噪音**：部分 B 股公司某年"不分配不转增"是因亏损或重组，属真断分红；但因股本变动暂缓的属假断，查公告原文确认。
- **净利率一次性损益**：资产处置、减值转回会抬高单年净利率（如粤高速B 2025 净利率 55.7%），判定时看一眼扣非或剔除非经常项后的口径。
- **B/A 比价**：B 股对 A 股折价 30–60% 普遍存在，折价深度不是筛选维度（本筛选不看价格），但报告可附注供后续估值参考。
