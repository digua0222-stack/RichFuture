# 第 3 道门 · 毛估估估值方法

只在前三道门全部通过后执行。段永平："未来现金流的折现是思维方式，不是算法，不要企图拿计算器算出来。"目标是**用保守假设把账算清**（林园："必须知道多少钱了，我们才会出手"），而不是追求精确数字。

## 目录

- 股东盈余
- 折现框架
- 安全边际
- 输出要求

## 股东盈余（估值起点）

```
股东盈余 = 净利润 + 折旧摊销 − 维持性资本开支
```

- 区分维持性与扩张性资本开支：只用维持性部分扣减。无法拆分时用总额，更保守。
- 交叉验证：股东盈余应与经营现金流同量级；长期偏离要给出解释，解释不了就降档假设。

## 折现框架（毛估估）

- **期限**：10 年显性预测 + 永续（或保守终值）。能看 10 年是前三道门已确认的前提。
- **增长率**：分两档或三档，全部取保守值。参考公司历史再投资回报率与行业空间，禁止线性外推历史最高增速。
- **折现率**：投资者机会成本，不低于无风险利率（国债收益率）。常用 8%–10% 作为默认机会成本。
- **终值**：永续增长率 ≤ 长期 GDP 增速（默认 ≤ 3%）。
- 做敏感性检查：增长率 ±2 个百分点、折现率 ±1 个百分点各算一遍，给出区间而非单点。

## 安全边际

```
通过条件：当前市值 < 内在价值保守估计 × 0.6–0.7
```

- 用毛估估区间的**下沿**再打折，不是用上沿。
- 段永平："至于低 40% 还是 50%，完全由投资人自己的机会成本决定。"确定性越弱的公司，要求的折扣越大。
- 算不出保守区间、或区间宽到无意义 = 没看懂 = 否决，回到第 0 道门原则。

## 输出要求

```
股东盈余（近 3 年）：……
关键假设：增长率 / 折现率 / 永续增长率（各给依据）
内在价值区间：下沿 …… 上沿 ……
当前股价：……（报价币种 + 日期，换算报告币种标注汇率）
估算中枢股价：……（内在价值中枢/股）
当前市值 与 安全边际：市值 ÷ 区间下沿 = ……
结论：通过 / 不通过（差多少个百分比）
```

**全标的强制输出（含被否决标的）**：当前股价与估算中枢股价是每只标的（含否决标的）的必填输出。当前股价取自最新行情快照（`listings[].last_close` + `date` + `currency`，折算用 `fx_to_report_currency`）；估算中枢股价 = 内在价值中枢 ÷ 总股本（`share_capital`）。否决标的用保守假设（g 取第 2.55 道叙事推断档位下限或更保守），并标注"参考值——否决后不作买入依据"，用于对照现价距中枢的偏离（便宜但坏 vs 贵且坏），不作为买入信号。
