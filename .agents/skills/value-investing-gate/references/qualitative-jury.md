# 第 2 道门 · LLM 定性陪审团流程

财务代理硬闸通过后执行。原则：**财务代理回答"过去有没有"，LLM 回答"未来还在不在"。** 两种证据必须交叉验证，任何一方证伪即否决。

## 目录

- 输入材料
- 四个必答问题
- 证据链规则（反幻觉）
- 输出结构

## 输入材料

按可得性读取：近 3–5 年年报"经营讨论与分析"、招股书（若上市不久）、管理层公开访谈/致股东信、量价拆分数据、关联交易与分红回购记录、行业格局资料。

## 四个必答问题

1. **差异化是否真实且可长期维持？** 产品是否"用户需要但别人满足不了"（段永平定义）。区分"差异化"与仅仅是"不同"。
2. **提价权在不在公司手里？** 查历史提价记录及提价后销量是否受损（年报量价拆分）。提价后量不跌 = 真提价权。
3. **垄断/成瘾属性？** 护城河类型（品牌心智 / 牌照监管 / 绝密配方 / 网络效应 / 转换成本），产品是否重复消费、有依赖性（社交、疗效、习惯）。
4. **企业文化与资本配置？** 管理层言论与行为一致性、历史承诺兑现记录、是否"做对的事情"、有无利益输送/激进关联交易、分红回购是否慷慨。

另需回答总纲问题：**10 年后这家公司大概率活得好吗？** 考虑需求端结构性变化（老龄化、消费习惯迁移、技术替代）。说不清即否决。

## 证据链规则（反幻觉）

- 每个结论必须附证据：年报原文引用（注明年份/章节）或具体财务数据。
- 证据不足、材料缺失、结论依赖"可能/有望/前景广阔"等叙事词 → 一律判"不通过"。
- 年报文本本身是管理层写的，保持怀疑：叙事必须与财务数据交叉验证（如声称提价权，毛利率趋势必须支持）。
- 禁止过度乐观偏差：把平庸公司讲成伟大公司，比错过好公司更危险。拿不准就否决——错过的成本远低于做错。

## 输出结构（固定五段）

```
护城河类型：（品牌/牌照/配方/网络效应/转换成本/无）
提价权证据：（量价数据 + 引用）
文化信号：（管理层言行记录 + 引用）
十年后形态：（需求趋势判断 + 依据）
否决理由：（若无充分证据，写明缺什么）
```
