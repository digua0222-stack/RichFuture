# 叙事推断（Narrative Inference）

定位：**叙事不是事实证据，是推断。** 数据回答"是什么"，叙事推断回答"意味着什么"——用常识把已核验的事实串成因果链，覆盖数据无法直接给出的部分（慢变量惯性、结构趋势、终局形态）。

第一性原理：价投必须同时用两类输入——**只信数据会漏掉结构性慢变量**（老龄化不可逆、品牌复利后置），**只信叙事会掉进故事陷阱**（"下一个片仔癀"）。本清单定义：什么叙事合法、什么叙事非法、合法叙事如何提高权重。

与 M1–M6 的关系：M 系列回答"数据可不可信"，本清单回答"**推断合不合法、权重怎么调**"。

## 零、总架构：十年后受众反推（动态规划模式，DP-Audience）

**一切受众/永续性分析的唯一入口。** 目标函数固定：**T = 十年后付费受众人群 × 人均强度**——不是患者总数、不是市场规模金额，是 10 年后真实掏钱的人群及其消费强度。从 T 反推依赖项，逐层分解到边界条件，建拓扑边，再正向聚合回 T。类比动态规划：

| 动态规划 | 受众反推架构 |
|---|---|
| 状态定义 | 目标任务数据 T = 十年后付费受众 × 人均强度（人数 × 频次 × 单价） |
| 状态转移方程 | **行业分解式**（T = 各一级因子的乘积/加和结构，合法性来自二点七行业常识底座） |
| 最优子结构 | 每个因子的 10 年方向可独立分析，再聚合 |
| 边界条件 | 已核验硬数据（人口普查/官方统计/政策文件/临床指南）或不可再分的慢变量 |
| 备忘录（重叠子问题去重） | **共享驱动因识别**——同一底层变量驱动多个上层节点时，禁止独立相乘，必须合并为联合效应（二点八） |
| 递推方向 | 反推分解（backward）→ 正向聚合（forward） |
| 解的校验 | 每层可证伪观测点，逐年校准重写 |

### 执行五步

**第 0 步 · 定义 T（可计量）**：写成"人数 × 人均年消费"形式。反例：T ≠ "3.3 亿心血管患者"（统计总数 ≠ 付费受众）。

**第 1 步 · 一级分解（直接依赖项）**：按行业分解式展开 T。**分解式原型必须取自 `references/audience-models.md` 计算模型注册表**（选择协议：先判付费行为类型 → 取原型 → 多层分模；无匹配则按 schema 新建原型入册），原型自带合法算法与专属校验；分解式中各率值的数值合法性由行业常识底座供给（二点七）。**禁止裸写乘积链。** 原型示例：
- 药品：T = 患病人数 × 症状率 × 自我药疗选择率 × 品类偏好 × 品牌份额 × 人均强度
- 白酒：T = 宴请场景数 × 开瓶率 × 价位带选择 × 品牌份额
- 煤炭：T = 发电量 × 煤电占比 × 单位煤耗 × 公司份额

**第 2 步 · 递归反推至边界条件**：每个因子继续问"由什么决定"，直到撞上已核验硬数据或不可再分慢变量。例：患病人数 ← 出生队列结构 × 患病率年龄斜率 × 发病率趋势 × 筛查确诊率。**禁止停在总量口径**（总量发病率/总人口）——总量是聚合幻觉，结构才是因果载体（2026-08-02 达仁堂四/五轮教训：婴儿潮队列移入高患病率年龄段，总量口径低估人数端 ~20-30%；且**子段增速禁止直接当聚合增速**，必须按权重加权，见二点八·数据层拓扑）。

**第 3 步 · 拓扑建边（共享驱动因去重）**：分解树建成后做跨层边检查——同一底层变量是否驱动多个上层节点？（年龄 → 患病人数、症状率、自我药疗强度；医保支付能力 → 集采降价、目录调整、处方行为）共享驱动因的节点**合并为联合效应**，不得独立相乘（否则双重计算或漏算对冲）。双向/双刃节点、长传导链、反馈回路按二点八处理。

**第 4 步 · 正向聚合 + 输出形态**：沿拓扑从边界条件正向计算 T 的 10 年轨迹。输出**不是单点值，是条件分布**：稳态基准 + 开关期权（枢纽节点的触发场景）。每层附可证伪观测点。

**第 5 步 · 估值接口**：T 的聚合结果 → 量的假设 → 结合价/利润率 → g → DCF。g 的合法来源 = T 的聚合；第 2.5 道映射表只作天花板，禁止作数字来源。

### 与后续各节的关系

N1–N3 审链条合法性（第一节）；二点七提供**分解式的合法性**（行业常识底座：分解式怎么写、每层用什么常识）；二点八提供**建边规则**（共享驱动因/双向节点/传导链/反馈回路/稳态与开关）；本节是二者的统摄与执行顺序。完整实例见 `reports/2026-08-02_达仁堂叙事复核_医疗常识专项_kimi.md`（四轮迭代：断环 → 漏斗 → 拓扑 → 队列效应）。

## 一、合法性三问（N1–N3，先审链，再谈权重）

**N1 · 事实骨架**：叙事链的每一环，是否都有一个已核验的事实锚点（年报数字 / 人口统计 / 监管文件 / 公司公告）？任何一环悬空 = 整链非法。

**N2 · 常识因果**：环与环的连接，是否"不需要专业知识、仅凭常识即可成立"？连接处出现专业假设（如"25% CAGR 可连续十年"）或行业黑话，该连接降级为待验证，不能参与加权。

**N3 · 无类比偷懒**：是否存在"下一个 X"式类比代替论证（"下一个片仔癀""药中茅台"）？类比是营销不是论证——类比只能提示研究方向，不能作为权重来源。

## 二、叙事加权规则（权重调节器）

叙事**不制造新事实**，只调整已有结论的权重档位。调整只发生在合法区间内：

| 叙事质量 | 权重效果 | 边界条件 |
|---|---|---|
| 事实骨架全有 + 常识因果全通 | 结论可从"中性"升至"偏强" | 不得突破第 2.5 道映射表上限 |
| 事实骨架有，但 ≥1 环靠专业假设 | 权重不变，标注"待验证" | 等待可证伪事件（如集采结果、下季报） |
| 类比 / 链条断裂 / 人群口径错位 | 权重下调或否决该叙事 | 该叙事不得进入结论 |

**档位规则**：
- 叙事可以把 g 从合法区间下沿移到上沿，但不能创造区间外的 g（g 仍受 M3 溯源码约束——叙事标注"来源类型：叙事推断（N1–N3 通过）"）。
- 叙事可以提高对"报表噪音"的容忍度（短期量降 vs 长期受众扩张），但前提是 N1–N3 全过。
- 叙事结论进入报告必须标注 `（叙事推断）`，与 `（事实）` 分离；强判断词哨兵（M6）对叙事同样生效。

## 二点五、叙事先行协议（先讲故事，再验数据）

**叙事先行不是"平行调节"，而是执行顺序**：叙事是推断的第一输入，数据/指标是第二输入。顺序固定为四步：

1. **建链（故事先行）**：凭常识把已核验事实串成因果链，回答"10 年后这家公司长什么样"。这一步**故意先不看财务指标**——指标描述过去，回答不了"惯性会不会持续"。先讲一个讲得通的十年故事。
2. **校验（N1–N3）**：对链条逐环审查——N1 每环有已核验事实锚点？N2 环间仅凭常识即可成立（无专业假设）？N3 无类比偷懒？任一不通过，该链作废或降权。
3. **落地（数字导出）**：通过校验的叙事链导出第 2.6 道五要素数字（量/价/利润率/再投资/终局）与 g 取档——**叙事决定 g 的档位语义**（为什么是 6% 而不是 3% 或 9%），数据决定 g 的具体值。
4. **证伪（数据后验）**：受众数据与财务代理反向校验故事。数据矛盾 → 数据优先，故事重写或弃用；数据不矛盾 → 故事成立，按第二节加权规则调节。

**为什么永续性依赖叙事先行**：永续性是"10 年后还活得好不好"的推断，而推断的第一形态就是故事。数据能证明"过去 3 年毛利率 74%"，但证明不了"未来 10 年提价权还在"——后者只能靠"独家保密配方（事实）→ 组内无竞争者（事实）→ 集采打不到它（常识）→ 提价权持续（叙事推断）"这样的常识链。**数据是故事的证据，不是故事的替代品。** M 系列（M1–M7）解决"数据可不可信"，N 系列解决"故事讲不讲得通"——两者都健全，推断才健全；指标健全而叙事缺席的报告，永续性判断必然失真。

## 二点六、因果链审核：证实与证伪（叙事审核的生死环）

**审核叙事的核心不是"故事好不好听"，而是"链条结不结实"：每一条叙事条目必须①基于事实（锚点）、②经得起常识推断（连接）、③尊重因果链（闭合）。三者缺一，该叙事不合法。** 以下三查 + 双向验证是审核的固定动作。

### 因果链三查（先审链，再审权重）

1. **锚点全覆盖**：链条每一环都必须有已核验的事实锚点（年报数字 / 公开统计 / 监管口径 / 公司公告）。允许"一环一锚"，禁止"多环共用一锚"或"无锚跳步"。
2. **连接常识化**：环与环之间仅凭常识即可成立（无需专业假设 / 行业黑话）。出现专业假设（如"25% CAGR 可持续十年"）的连接降级为待验证，不参与加权。
3. **链条闭合**：链条必须能从起点事实走到终点结论，全程无断裂、无跳步。终点结论若依赖"不可知/无法预测"，视为链条未闭合——必须返回拆解"到底是哪一环不可知"，禁止把"不可知"当作终点。

### 证实与证伪（双向验证，缺一不可）

- **证实（正向）**：链条每一环都能找到支持性证据 → 证据支持叙事，叙事才可进入加权。
- **证伪（反向）**：任一环出现矛盾数据 → **数据优先**，故事重写或弃用（"叙事说放量，数据说去库存，应信数据"）。
- **反否定对称性（对称规则）**：**否定一个叙事，也必须提供事实锚点**——"十年后不可预测"这类无锚点否定，与"下一个片仔癀"这类无锚点肯定，同为非法叙事。凡写"看不懂/不可预测/无法判断"，必须回答：哪一环断了？断环处的事实依据是什么？答不出，该否定本身作废。

### "不可知"陷阱（周期股审核必查）

周期品（煤炭/钢铁/化工）的**"价"确实难预测，但"量/受众"往往是可锚定的慢变量**（煤炭看电力结构与煤电定位、钢铁看地产周期、化工看下游产能周期）。"价不可预测" ≠ "链条断裂"——把受众慢变量拆出来建链（如：需求结构 → 电气化/地产 → 行业集中度 → 龙头份额），链往往能闭合，只是档位低（第 2.5 道"受众收缩但集中度提升"档）。**对周期股一律先做受众推断再决定可否决，禁止用"不可知"跳过建链。**

*实证（2026-08-02 伊泰B股二审）：初审用"煤价十年后无可锚定常识因果"否决叙事，该断言自身违反 N1；二审按能源用度常识建链（煤炭消费结构电力~60% → 电气化/地产 → 集中度 → 长协政策底）后链条闭合，结论从"断裂"修正为"可锚定但中偏弱"，否决理由从"看不懂"升级为"可预测的衰退 + 硬指标不达标"。*

## 二点七、行业常识底座（叙事先行的前置条件，行研语料禁令）

**病灶**：N2 要求"仅凭常识即可成立"，但"常识"若默认成大众常识，叙事链就会退化为"老龄化→用药增多"式的人口学直线推导——医药行业真正的常识（临床路径、支付方行为、循证竞争、替代技术）反而被当作"专业知识"排除在外。**行业缺席的常识链，比没有常识链更危险：它给出虚假的方向确定性。**

### 核心规则

1. **常识分两层**：大众常识（人口学、消费习惯）只负责方向感；**行业常识（该行业从业者/监管者/临床视角的因果结构）负责因果链主体**。只用大众常识建成的叙事链 = "底座缺失"，权重最高"待验证"，不得参与 g 取档。
2. **叙事先行第 0 步（在"建链"之前）**：先构建**行业常识底座**——回答该行业的一阶因果变量清单。清单由行业决定，必须逐条给出来源：

   **医药六问（模板，其他行业仿此自建）**：
   1. **流行病学**：本病患病人群怎么变？（**患病率年龄斜率 × 出生队列结构**，而非总人口、也非总量发病率外推——患病率随年龄递增的病种，在婴儿潮队列移入高患病率年龄段的窗口期，人数端增速会被总量口径系统性低估；反之，窗口期效应不是永续现象，不得外推进 gterm）
   2. **临床路径**：本病主流治疗路径是什么？本品在一线 / 辅助 / 替代哪个环节？（指南地位 + 证据级别）
   3. **证据等级**：本品与竞品的循证层级（硬终点 RCT / 症状终点 RCT / 经验用药）？未来 10 年分化主线是否循证？
   4. **支付方**：谁付钱？集采 / DRG / 目录调整在降价还是扩面？价格假设必须与支付方周期一致。
   5. **替代技术**：什么疗法 / 技术在截流这个需求？（如介入手术对症状缓解药的截流）
   6. **监管周期**：注册 / 价格 / 生产政策在哪个阶段？

3. **行研语料黑名单**：以下内容**只能作背景校验，禁止充当因果链环**——市场规模与 CAGR 引用（"千亿市场 CAGR 5-7%"）、"赛道"、"渗透率提升"（无驱动因的）、"受益于老龄化 / 消费升级"（无中间机制的）。**识别标志：删掉该引语后链条逻辑不变 = 它本来就没在承重。**
4. **底座来源优先级**：监管与指南原文（卫健委 / 医保局 / 临床指南）＞ 循证文献（PubMed / Cochrane / 顶刊）＞ 行业协会与官方统计 ＞ 企业公告 ＞ 券商研报（仅作线索入口，结论必须回溯一手来源）。**每个因果环至少一个一手专业来源。**
5. **跨学科调研义务**：进入非熟悉行业，必须先完成底座构建再叙事先行；底座缺失时**禁止给出受众轨迹结论**，输出"底座不足 + 待调研清单"。宁可标注不懂，不可用大众常识冒充行业常识。
6. **N2 修订**："常识因果"中的"常识" = 行业常识底座内的常识（附来源），不是路人常识；未经底座构建的专业假设仍然非法。

### 常识三用（底座的正向产出：理解数据 → 补完受众 → 生成前瞻）

> 底座的用途不只是证伪叙事（防守），更是**生产 10 年后的数据**（进攻）。只用于否决的常识底座只发挥了一半价值；它的最终目的是让"10 年后的数字"从机制中长出来，而不是从映射表里取出来。

**用途 A · 理解数据（把会计数字翻译回物理世界）**
任何关键经营数字必须能翻译成"多少人 × 什么频率 × 什么价格 × 什么渠道"：21.66 亿销售额 = 多少真实用户、日常服用还是抽屉备用、年消耗几盒、单价几元。**翻译不出来的数字 = 没理解的数据，禁止进入因果链**——会计数字描述结果，物理结构才承载因果。

**用途 B · 补完真正受众（受众漏斗协议，替换"总数式受众"）**
统计口径的受众总数（"3.3 亿心血管患者"）几乎从不等于真正受众。真正受众必须经**漏斗**逐层还原：

```
统计总数 → 逐层转化（每层三要素：转化率赋值 + 常识/来源依据 + 10年方向与可证伪观测点）
示例：患病人数 →×确诊率→ ×症状率→ ×自我药疗选择率→ ×品类偏好→ ×品牌份额→ ×依从性/年复购
```

- 漏斗末端（日常依赖用户）才是收入引擎；漏斗中层（备用/心智人群）是品牌资产，贡献盒数不贡献主收入，**两层必须分开定价**。
- **行业决定漏斗总量，公司只能改变漏斗内份额**——受众推断答"总量方向"，护城河判断答"份额方向"，二者不得混用。
- 每层转化率允许估算，但必须标注"估算 + 常识依据"；无依据的层标"待调研"，禁止跳过。

**用途 C · 生成前瞻数据（预设数据的合法来源，优先级强制）**
第 2.6 道五要素（量/价/利润率/再投资/终局）与 g 的数字来源优先级：
1. **漏斗推导**（每层 10 年方向的聚合：层 1↑ × 层 2-4↓ × 价→ = 净效应）——首选，机制透明、可逐年验证修正
2. **历史同口径复合增速**——仅作交叉校验（历史不含路径变迁与支付周期突变时系统性偏乐观）
3. **映射表取档**——只作合法性天花板，**禁止作为数字来源**
- 输出必须含**聚合构成**（"g1=2% 的构成：确诊人数 +2.5%/年 × 症状率与自我药疗 -1.5%/年 × 价 0%/-1% ≈ 1~2%"），不含构成的 g 一律视为取档偷懒。

### 实证：达仁堂（2026-08-02 医疗常识复核）

- **原链**（2026-08-01）："老龄化 → 心血管受众扩张（强）→ g1=5%/gterm=2.5%"——通过 N1–N3，但底座缺失：未答临床路径（速效在急救主线之外，指南定位=症状缓解）、支付方（中成药集采降幅 42%→63% 逐批加深、独家 47%、OTC 已入第四批射程）、循证（竞品麝香保心丸 MUST 硬终点研究 vs 速效无硬终点 RCT）、替代（PCI 手术量 CAGR 14-17% 截流症状需求）四问。
- **复核结论**：受众轨迹从"扩张（强）"下修为"**稳定偏收缩**"，g1 5%→2–3%，gterm 2.5%→≤1%，终点"相当偏强"→"相当"。详见 `reports/2026-08-02_达仁堂叙事复核_医疗常识专项_kimi.md`。
- **教训**：**人口学顺风是医药叙事最常见的伪底座。** 老龄化使病人变多是大众常识；"病人用什么治、谁付钱、证据给不给它位置"才是决定药品市场 10 年方向的行业常识。

## 二点八、因果拓扑（数据联动：从"链条"到"有向图"）

**病灶**：链条式叙事把数据节点当**独立变量做静态乘积**（漏斗层 A×B×C×D、断环并列罗列）——但真实系统里节点彼此有边：同一个老龄化既在分子（受众↑）又在分母（支付压力→降价↑）；PCI 既截流存量又创造术后增量。**无视拓扑的叙事，单点变动面前必然错判：牵一发，动全身。**

### 拓扑审查六步（第 2.6 道 g 导出前的强制动作）

1. **节点关联审查**：列出叙事中全部数据节点，两两问"是否存在因果边？"——禁止把相关变量当独立变量相乘；有边变量必须合并为联合效应表述。
2. **双向/双刃节点识别**：任何一阶变量必须问"二阶效应是否反向？"（老龄化：受众 +、支付压力 −；PCI：截流 −、术后增量 +；集采：价 −、以价换量 +）。只写一阶效应的节点 = 审查未完成。
3. **长传导链识别**：找出跨越 ≥3 节点的传导链（循证→指南→处方→院内→心智→OTC）——**最长的链条最被忽视，且往往攻击最核心的资产**（心智/品牌/护城河）。链条时滞若落在估值窗口内（如 8-10 年），必须计入。
4. **反馈回路识别**：正反馈（单品依赖→资源倾斜→第二梯队更弱→更深依赖）判断打破它需要的外力；负反馈（降价→放量→摊薄）判断新稳态的位置。
5. **枢纽节点场景推演**：找出出边最多的 2-3 个枢纽，各做至少一次"触发 → 级联 → 终态 → g 重估"推演（含方向与量级）。
6. **稳态与开关**：明确系统当前吸引子（如"销售额平台期"），列出打破吸引子的开关及其方向（向下/向上/双向）。**g 的正确表述 = 稳态基准 + 开关期权**——开关不触发时 g 取稳态值；开关价值单独评估，不并入基准假设。

### 数据层拓扑（边界条件节点间的建边义务，2026-08-02 五轮补入）

拓扑义务不止于叙事节点——**边界条件（硬数据/慢变量）彼此之间同样有边**。三条强制校验：

1. **分层增速归属校验**：子人群（如 65+）的增速禁止直接当作聚合层（患者总数/用药人群）的增速。**聚合增速 = Σ(分层权重 × 分层增速)**，权重必须显式给出（如 65+ 患者占 ~65%）。把子段 +4~5% 直接接入聚合，会把增长高估约 1.5-2 倍。
2. **队列算术校验**：凡引用"队列 + 窗口年份"，必须显式演算 **出生年 + 窗口年 = 队列年龄**，并核对阈值事件（跨 60/65/80 岁）的真实年份——算术错误会直接错配窗口起止与熄火机制（如"2036 后进入 80+"实为 2042+）。**分层表强制队列世系法（cohort-component）**：band(t+Δ) = band(t) 前移 Δ 岁 × 该段存活率，锚定最近一次人口普查 5 岁组；**禁止用"已核验总量的内部分配"代替世系投影**（2026-08-02 七轮教训：分配法使 60-64 层两年各低估 ~900 万、层差碰巧接近纯属运气；且 2035 年某层人口 ≠ 2025 年同层人口，而是 2025 年 [层−10 岁] 人群 × 10 年存活率）。
3. **边界节点建边**：人口结构节点（60+ 与 65+ **分开计量**，二者增速可差 2.7 倍）× 患病率斜率节点（横截面）× 患病率漂移节点（时间方向：中国=上升 / 美国=下降，方向相反不可混引）× 诊断率节点（确诊 = 患病 × 诊断率，禁止把患病增速直接安在确诊头上）× 用药结构节点（用药人群年龄偏老 → 其增速介于患者总数与 65+ 段之间）。**缺一条边，漏斗就在该层口径错位。**
4. **横截面斜率 ≠ 队列轨迹（APC 校验）**：横截面年龄斜率混合年龄效应 / 队列效应 / 时期效应——今天 85 岁者的高患病率含其特有暴露史（吸烟高峰、高盐、未治高血压年代），不是"任何人活到 85 岁都会达到"的纯年龄规律。用横截面斜率给某队列做 10 年外推，等于默认"斜率 = 纯年龄效应"——**这是专业假设而非常识，按 N2 该连接降级为待验证**：链条只可承"方向"，不可承"点值"，除非有队列内轨迹数据（如 China-PAR / CKB 随访的年龄别发病率）校验。方向冲突暴露史须同时列出（1962-75 队列：肥胖/糖尿病更糟 ↑ vs 他汀/血压控制更好 ↓），禁止只写单向。
5. **存量 × 分层概率积分校验（患病人群禁止用增量/代理法）**：患病人群是**存量系统**——患者(t) = Σ_band Pop(band,t) × Prev(band)，逐年龄层存量 × 该层患病率、逐层相乘再求和。三层强制：①**人口侧与患者侧分开校验**——流量法（跨入−死亡=净增）只能校验人口净增，禁止当作患者数校验；②**层内对冲项必须成对写**——新进入者拉低层均患病率（稀释）vs 存量沿斜率上行（抬升），二者抵消程度决定"患者增速 vs 人口增速"的偏离方向，禁止只写一项；③**阈值事件按患者侧重算**——人口换挡 ≠ 患者换挡（人口净增放缓后，存量沿斜率上行仍可维持患者正增长多年），"熄火/换挡"年份不得从人口侧直接搬。

**实证（2026-08-02 达仁堂五轮）**：框架原将"+4~5%/年"标注为"人数端"增速并接入聚合——经三验（队列流量法 / 2025 实测 65+ 仅 +342 万锚点 / 患者加权法），该数字实测仅属于 60+ 人口当下口径；65+ 窗口峰段 +3.7~4.5%、患者总数 +2.5~3%、用药人群 +3~3.5%。聚合从 +0.8~1.8% 下修至 -0.2~+0.8%，g1 收敛至 0~1%。同案另纠正两处：香港"85+ 7.7%"引用与调查覆盖口径（15-84 岁非住院自报）冲突，降级待核；"2036 后进入 80+"系队列算术错误（应为 2042+；真实机制 = 2035 前后 65+ 增量换挡）。

### 实证：达仁堂（2026-08-02 三轮深化）

- 五个枢纽节点：PCI（双通道：截流 − vs 术后增量 +）、支付方（三通道：价 −/换量 +/清退 −）、循证（5 节点长链，攻击"心智托底"假设本身）、老龄化（双刃，二阶负向随时间递增）、低价药目录身份（提价封顶 × 成本上涨的钳形）。
- 主传导链：竞品硬终点 RCT→指南→处方→院内→代际心智侵蚀，时滞 8-10 年正落在估值窗口内 → "心智层托底"假设从"永续"修正为"有效 5-8 年"。
- 终态表述：g 从固定值改为条件分布——平台期基准 g1=0~1%，集采/RCT/低价药政策三开关作期权单列。

## 三、叙事与六道门的接口

- **第 2.5 道受众推断**：数据回答"受众规模怎么变"，叙事回答"变多久、惯性多大"——老龄化人口的不可逆性就是叙事（队列已成、不可逆），它支撑受众扩张的持续性加权。
- **第 2.6 道十年后推断**：**叙事先行**——先建十年图景的叙事链（量→价→利润率→再投资→终局，环环因果自洽），再逐环做 N1–N3 校验，最后用财务指标/受众数据证伪。讲不通 = 没看懂 = 否决；讲得通但指标矛盾 = 数据优先，故事重写。
- **第 3 道估值**：叙事不改变 DCF 结构，只影响 g 取档与置信区间宽度。

## 四、反叙事陷阱（必须压制的四种叙事）

1. **类比叙事**（"下一个片仔癀"）→ 压制。片仔癀是日服保健逻辑，速效救心丸是急救场景逻辑，产品属性不同，类比即误导。
2. **人群口径错位**（"3.8 亿老人 = 3.8 亿消费者"）→ 压制。潜在患病人群 ≠ 消费人群，中间隔着"发病率 × 就诊率 × 用药依从性"，口径必须先统一。
3. **属性拔高**（急救药 → "成瘾复购"）→ 压制。复购频率由**产品属性**决定，叙事不能改写属性。急救药低频、慢病药高频、保健药日频，属性定频率。
4. **叙事与数据矛盾** → 数据优先，叙事必须重写或弃用（e.g. 叙事说"放量"，数据说库存 -56% 去库存，应信数据）。

## 五、达仁堂实证（2026-08-01 核查）

- **合法叙事**："60 后婴儿潮进入高龄 → 心脑血管患病率随年龄上升 → 速效救心丸使用场景增多"——每环有事实锚点（60+ 人口 3.23 亿、+2000 万/年 [Source: 民政部/国家统计局]），环间是常识因果 → 老龄化顺风的**持续性**权重"偏强"，支撑 g 取区间上沿而非下沿。
- **非法叙事 1**："急救药 = 成瘾复购"→ 属性拔高，压制。速效是"发病时吃 14 粒"的急救场景，非日常复购品。
- **非法叙事 2**："下一个片仔癀"→ 类比偷懒，压制。
- **边界叙事**："20 亿 → 200 亿单品"→ 事实骨架有（提价权 + 老龄化），但因果要求 25% CAGR 连续 10 年（约为历史实际增速 +9.26% 的 2.5 倍，属专业假设而非常识）→ 权重降至"偏弱"，只保留"方向正确、时间框架激进"的结论，2025 实际增速验证为 ⚠️。
- **叙事对报表噪音的容忍**：2025 盒数 -5.16% 表面与"老龄化放量"叙事矛盾——按 M2 换算（规格调整、按粒数增长）后矛盾消解，叙事存活但必须依赖数据修正，这证明叙事不能独立于 M1/M2 生效。

> **勘误（2026-08-02 医疗常识复核）**：本节原将"老龄化→受众扩张"判为合法叙事并支撑 g 取区间上沿——该判定**底座缺失**（未答医药六问中的临床路径/支付方/循证/替代四问），经复核下修为"稳定偏收缩"，g 改取区间中下档（g1 2–3%、gterm ≤1%）。此案例直接催生了"二点七 · 行业常识底座"：**仅通过 N1–N3 的大众常识链不再足以证明受众扩张**。复核全文见 `reports/2026-08-02_达仁堂叙事复核_医疗常识专项_kimi.md`。
