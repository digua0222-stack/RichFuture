# 误断防制清单（Anti-Misjudgment）

触发场景：任何一次门禁分析 / 估值 / 标的讨论的**全流程**。本清单与六道门并列生效——六道门回答"公司值不值"，本清单回答"**我的判断可不可信**"。

第一性原理：大多数误判不是数据错，而是**口径错、单位错、假设无源、参照系缺位**。四条防自欺守则：

1. **口径关（M1）**——跨期对比前先问：这两个数在同一口径下吗？
2. **单位关（M2）**——量价拆分前先问：单位可比吗？
3. **溯源码（M3）**——每个增长率假设必须写得出出处，写不出就是感觉。
4. **参照系（M4/M5）**——自己的假设 vs 市场定价、自己的结论 vs 大师观点，必须对照。

---

## M1 · 跨期可比性检测（口径关）

- **触发**：报告期内发生业务剥离 / 并购 / 会计政策变更 / 口径重述（如 2025 达仁堂剥离医药商业板块、2024 年 11 月完成）
- **强制动作**：
  a. 禁止对口径变化年份做直接同比（营收、费用率、毛利率、净利率全部禁止）
  b. 先重建可比口径：用"同口径重述"或"剔除剥离板块"后的数字再对比
  c. 输出同比时必须标注口径标签：`（含商业混合口径）` / `（纯工业口径）` 等
- **可证伪条件**：若剔除剥离板块后趋势反转，原"恶化 / 改善"结论自动作废
- **实证（达仁堂 2025）**：
  - 表面：营收 -32.7%、销售费用率 26%→41% → 误判"费用失控"
  - 真相：-32.7% 是剥离商业板块的会计效应；纯工业口径营收 +8.64%、费用率 43%→42.5% 微降
  - 教训：26% 是含商业混合口径、41% 是纯工业口径，两个口径直接对比 = 伪结论

## M2 · 计量单位校验（单位关）

- **触发**：涉及销量 / 产量 / 库存 / 量价拆分
- **强制动作**：先确认计量单位可比（盒 / 粒 / 吨 / 升 / 规格 / 包装 / 浓度），单位变化必须换算成统一单位后再算量价；**"包装单位"不等于"消费量"**
- **可证伪条件**：若按统一单位重算后方向改变，原"量增 / 量减"结论自动作废
- **实证（达仁堂 2025）**：速效救心丸盒数 -5.16%、产量 -15.97%，表面"需求萎缩"；实为规格调整（120 粒 → 200/240/300 粒），按粒数折算实际销量增长，库存 -56% 为渠道去库存

## M3 · 假设溯源码（g 关）

- **触发**：设定 g1/g2/gterm，或"营收增速""净利增速"等任何前瞻假设
- **强制动作**：每个 g 必须标注溯源码，格式 `{来源类型: 具体出处}`，来源类型限三种：
  - 受众轨迹映射上限（第 2.5 道映射表）
  - 十年后推断量价拆解（第 2.6 道五要素）
  - 历史复合增速（近 3-5 年**同口径**）
  - 三者冲突时取最低，并写明为何放弃其他两个
- **禁止**：无来源的"感觉增速"；用**错误口径的历史增速**反推假设
- **可证伪条件**：假设无法标注来源 = 无效假设，须回到第 2.5/2.6 道重新推导
- **实证（达仁堂）**：旧假设 g1=g2=gterm=3% 无溯源码，且与 2025 工业 +8.64% 直接矛盾——比 S 股市场隐含增速（3.3%）还悲观，属于用当期悲观情绪反推假设

## M4 · 隐含增速对照（价格关）

- **触发**：得出"贵 / 便宜 / 高估 / 低估"结论**之前**
- **强制动作**：
  a. 用 Gordon 反推当前市价隐含永续增速：`g_implied = (PE × r − 1) / (PE + 1)`，r 取机会成本（默认 9%）
  b. 多个上市地分别反推（如 A 股 vs S 股），折价差额用隐含增速差解释
  c. 自己的 g 假设与市场隐含 g 偏离 > 2pp 时必须二选一解释：(i) 我的假设更对，证据是什么；(ii) 市场定价了我没看见的东西，是什么
- **可证伪条件**：无法解释偏离 = 假设可疑
- **实证（达仁堂 2026-07）**：A 股 38.29 元（PE 37.1×）隐含 g≈6.1%；S 股 2.79 USD（PE 18.2×）隐含 g≈3.3%；我的 3% 假设比 S 股还悲观，而中性现实（2025 工业 +8.64%）指向 6-8%——假设偏离在对照表里立刻暴露

## M5 · 大师观点对照（外部锚）

- **触发**：标的存在知名投资者公开观点（林园 / 段永平 / 巴菲特 / 芒格等）
- **强制动作**：
  a. 逐环复述大师叙事（每环原文或转述 + 出处）
  b. 每环数据验证：✓ 成立 / ✗ 不成立 / ⚠️ 需打折，必须给数据
  c. 结论与大师相反时，输出"我可能错的三条"；一致时，输出"大师可能错的三条"（防盲从）
  d. 标注分歧的第一性维度：时间窗（10 年 vs 1 年）/ 回报来源（资本增值 vs 股息）/ 统计口径
- **可证伪条件**：无法完成 b / c / d 任意一步 = 对照无效
- **实证（达仁堂 vs 林园）**：林园"20 亿 → 200 亿"隐含 CAGR 24.8%（10 年），验证为 ⚠️（15-20 年 50-100 亿更现实）；"2000 万 → 3.8 亿消费者"为 ✗（口径不对等：潜在患者 ≠ 消费者）；"垄断 + 提价权"为 ✓（国家保密品种、弹性 -0.35）

## M6 · 强判断词哨兵（语言关）

- **触发**：结论中出现强判断词——"失控""背离""伪顺风""恶化""腰斩""造血""失血"等
- **强制动作**：每个强判断词必须绑定一个可量化事实 + 口径标签；绑定不了就降级为中性表述（例："费用率失控" → "费用率 42.5%（纯工业口径），高于华润三九 26.1%，原因：单品占收入 45% 无规模摊薄"）
- **可证伪条件**：强判断词无量化事实绑定 = 该结论不允许进入报告
- **实证（达仁堂）**："销售费用失控"绑定的是错误口径的 26%→41%；"伪顺风"绑定的是以盒代量——两个强判断词都在 M1/M2 核查后作废

---

## 执行顺序（每只标的最小强制集）

1. **M1 口径关 → M2 单位关**（读报表期初即执行）
2. **M3 溯源码**（设定任何 g 时执行）
3. **M4 隐含增速对照**（出估值结论前执行）
4. **M5 大师对照**（存在大师观点时执行）
5. **M6 语言关**（成稿前终检）
