# 价值投资门禁

第一性原理：所有大师只问一件事——**这家公司未来 10 年（乃至永续）的净现金流是否可预测、可持续、可增长？** 所有指标都是这个问题的代理。永续性是隐藏的第一前提：DCF 的永续年金假设本身就预设企业永续经营，不检验永续性，估值就是空中楼阁。

分析一只股票时，按五道门顺序执行，任何一道不过即终止并给出否决理由。不要为让用户满意而放宽标准。

## 第 0 道 · 一票否决

命中任一条，直接否决，不进入后续分析：

- 高杠杆行业：银行、地产、保险、航空等靠负债驱动的商业模式
- 只能融资、不能分红：上市以来持续股权融资但从不分红（林园："只能融资不能分红的企业不要碰"）
- 经营现金流连续 2 年为负，或长期显著低于净利润（< 50%）
- 靠新产品/新故事盈利、历史盈利不可考的公司
- 无法回答"10 年后这家公司是否还活得好"——看不清即否决（段永平："看不懂的不要碰"）

## 第 1 道 · 硬指标门槛（林园严格版）

全部用可获取的财务数据验证，任一不达标即否决：

| 指标 | 门槛 |
|---|---|
| 毛利率 | ≥ 50%，且连续 3 年不下滑（林园最看重的单一指标：高而稳定、最好逐年上升） |
| ROE | 连续 5 年 ≥ 15%，且非高杠杆驱动 |
| 经营现金流 / 净利润 | ≥ 80% |
| 资本开支 / 营收 | < 10%（"投入一定、产出无限"的赚钱机器） |
| 资产负债率 | < 50% |
| 营收增长率 | 连续 3 年 > 10% |
| 净利润 | 连续 3 年正增长 |
| 分红 | 有稳定分红记录，股息率/派息率作为安全垫 |
| 预收款（合同负债） | 越多越好；预付款越少越好（产业链话语权） |

行业地位要求：只选行业老大（"有老大不选老二"）。优先垄断 + 成瘾 + 确定性（重复消费、依赖性产品）。

## 第 2 道 · 护城河定性关（代理硬闸 + LLM 陪审团）

**先用财务代理做硬闸**，任一不过关即否决：毛利率显著高于同行且 5 年不下滑；ROIC 长期 > 10%；合同负债/营收 高；商誉/净资产低；大股东质押率低、无频繁减持；分红回购记录真实。

**硬闸通过后，LLM 做定性陪审**，回答四个问题并强制证据链。详见 [references/qualitative-jury.md](references/qualitative-jury.md)。输出必须结构化为五段：`护城河类型 / 提价权证据 / 文化信号 / 十年后形态 / 否决理由`。每个结论必须引用年报原文或具体数据；证据不足一律判"不通过"。

## 第 2.5 道 · 永续性测试（20 年视角）

护城河回答"现在有多宽"，永续性回答"还能流多久"。DCF 的终值假设只有对通过本门的公司才合法。

**财务代理（gate_screen.py 自动计算，全用可得数据的全部年份）：**

| 代理指标 | 逻辑 | 门槛（PASS / REVIEW / FAIL） |
|---|---|---|
| 毛利率变异系数 CV | 盈利结构的时间稳定性，护城河不蚀的证据 | ≤0.08 / 0.08–0.15 / >0.15 |
| 营收最大单年跌幅 | 需求是否断过崖 | ≥-30% 未破位 / 破位即 REVIEW 以上 |
| 维持性再投入强度 (资本开支+研发)/营收 近 3 年均值 | 巴菲特"变化慢的行业"：不需持续大额投入才能保住地位的公司才配谈永续 | ≤10% / 10–15% / >15% |

**LLM 定性五问（全部答"是"才通过，强制证据链，同第 2 道规则）：**

1. **需求永续**：20 年后人们还需要这个产品吗？（成瘾/必需/文化惯性——林园的"嘴巴"、老龄化）
2. **产品惰性**：20 年内产品形态会大变吗？（烈酒、中药配方 vs 手机、软件——巴菲特只买"变化慢"的生意）
3. **颠覆免疫**：存在可想象的技术/替代品颠覆路径吗？答"有"即不通过
4. **再投入豁免**：维持竞争地位是否无需持续大额 capex/研发？（需要不断创新的公司，其"永续"永远在下一次创新成败的赌注上）
5. **林迪效应**：品牌/公司存续越久，预期剩余寿命越长——百年老字号加分；不足 10 年历史的公司原则上无法证明永续性

**联动估值关**：通过本门 → 永续增长假设合法（gterm ≤ 3%）；REVIEW → gterm 降为 0–1% 且安全边际取 0.6；FAIL → 不给终值，只做有限年限折现，且通常应在第 2.5 道即终止分析。

## 第 3 道 · 估值关（毛估估）

用股东盈余（净利润 + 折旧摊销 − 维持性资本开支）做 10 年毛估估折现，折现率取投资者机会成本（不低于无风险利率）。只在价格 < 内在价值 × 安全边际（0.6–0.7）时判"通过"。折现是思维方式不是计算器——敢用保守假设把账算清，才算看懂（林园："必须知道多少钱了，我们才会出手"）。详见 [references/valuation.md](references/valuation.md)。

## 输出格式

每只股票输出：

```
门禁结论：通过 / 否决于第 N 道门
否决或存疑理由：（具体数据 + 引用）
四道门逐项检查结果表
（若通过）内在价值毛估估区间 与 当前价格的安全边际
```
