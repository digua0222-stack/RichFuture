# 价值投资门禁

第一性原理：所有大师只问一件事——**这家公司未来 10 年（乃至永续）的净现金流是否可预测、可持续、可增长？** 所有指标都是这个问题的代理。永续性是隐藏的第一前提：DCF 的永续年金假设本身就预设企业永续经营，不检验永续性，估值就是空中楼阁。

**核心论断：十年后经营推断是价投的心脏。** 六道门的存在意义不是收集通过章，而是共同回答一个问题——"10 年后这家公司长什么样"：第 0/1 道门确认它今天配不配被推断，第 2 道门确认它的护城河能否撑到那天，第 2.5 道门确认那天还有多少人买它的产品，第 2.6 道门把答案写成数字，第 3 道门只为这幅图景定价。写不出十年后图景的公司，再便宜也不碰。

分析一只股票时，按六道门顺序执行，任何一道不过即终止并给出否决理由。不要为让用户满意而放宽标准。

## 第 0 道 · 一票否决

命中任一条，直接否决，不进入后续分析：

- 高杠杆行业：银行、地产、保险、航空等靠负债驱动的商业模式
- 只能融资、不能分红：上市以来持续股权融资但从不分红（林园："只能融资不能分红的企业不要碰"）
- 经营现金流连续 2 年为负，或长期显著低于净利润（< 50%）
- 靠新产品/新故事盈利、历史盈利不可考的公司
- 无法回答"10 年后这家公司是否还活得好"——看不清即否决（段永平："看不懂的不要碰"）

## 第 1 道 · 硬指标门槛（三档制）

**分档理念**：一刀切门槛会把"生意模式差异"误杀成"质地差异"——煤炭龙头永远过不了消费垄断的毛利率线，但不等于它不是好生意。三档不是好/中/差评级，而是**三种可投的生意类型**，档位决定及格线、估值方法与仓位属性。**档位越低，确定性补偿越严格**：现金流要求不降反升、终值增长归零、安全边际加深。降档 ≠ 放松，而是换一把与该模式匹配的尺子；三档全 FAIL 依然是否决。

### 档位总表

| 档位 | 生意模式 | 估值方法联动 | 仓位属性 |
|---|---|---|---|
| **S · 林园档**（永续复利型） | 垄断 + 成瘾 + 重复消费，"投入一定、产出无限" | gterm ≤3%（仍受 2.5 道映射约束），mos 0.6–0.7 | 底仓 |
| **A · 巴菲特档**（稳健价值型） | 优秀但非印钞机：行业龙头 / 二线品牌 / 成熟期稳健企业 | gterm ≤2%，mos 0.6 | 主仓 |
| **B · 周期档**（中值回归型） | 强周期龙头：盈利随价格周期大幅波动，但成本优势与现金流真实 | **强制** base=周期中值股东盈余、gterm=0、三口径 DCF（保守/中枢/乐观），mos=0.65 按中枢口径 | 周期仓（禁止当底仓，报告强制标注） |

### S 档 · 林园档（永续复利型）

全部用可获取的财务数据验证，任一不达标即降档判定：

| 指标 | 门槛 |
|---|---|
| 毛利率 | ≥ 50%，且连续 3 年不下滑（容忍 ≤0.5pp 微观波动；林园最看重的单一指标：高而稳定、最好逐年上升） |
| ROE | 连续 5 年 ≥ 15%，且非高杠杆驱动 |
| 经营现金流 / 净利润 | 近 3 年均值 ≥ 80%，且无单年 < 50%（容忍单年扰动，拒绝持续性现金失血） |
| 资本开支 / 营收 | < 10%（"投入一定、产出无限"的赚钱机器） |
| 资产负债率 | < 50% |
| 营收增长率 | 连续 3 年 > 10% |
| 净利润 | 连续 3 年正增长 |
| 分红 | 有稳定分红记录，股息率/派息率作为安全垫 |
| 预收款（合同负债） | 越多越好；预付款越少越好（产业链话语权） |

行业地位要求：只选行业老大（"有老大不选老二"）。优先垄断 + 成瘾 + 确定性（重复消费、依赖性产品）。

### A 档 · 巴菲特档（稳健价值型）

| 指标 | 门槛 |
|---|---|
| 毛利率 | ≥ 30%，且近 5 年累计降幅 ≤ 5pp（允许慢变量波动，不允许结构失控） |
| ROE | 近 5 年均值 ≥ 15%，且最近 3 年每年 ≥ 12%（允许单年波动，不允许平庸化） |
| 经营现金流 / 净利润 | 近 3 年均值 ≥ 80%，且无单年 < 50%（**与 S 档同标准，现金流不打折**） |
| 资本开支 / 营收 | < 12% |
| 资产负债率 | < 55% |
| 营收 | 连续 3 年 > 0，且近 5 年 CAGR ≥ 3%（允许低增长，不允许收缩） |
| 净利润 | 连续 3 年无亏损，且近 5 年 CAGR ≥ 0 |
| 分红 | 有分红记录 |

行业地位要求同 S 档（只选老大）。**M7 垄断+提价型豁免适用 S/A 两档。**

### B 档 · 周期档（中值回归型）

核心切换：**逐年达标 → 周期均值达标**。判定窗口 ≥ 5 年且须含至少 1 个下行年（营收或净利负增长年），不足 5 年按 INSUFFICIENT 处理。

| 指标 | 门槛 |
|---|---|
| 毛利率 | 周期均值 ≥ 25%，且毛利率 CV ≤ 0.25 |
| ROE | 周期均值 ≥ 10%，且窗口内亏损年 ≤ 1 个 |
| Σ经营现金流 / Σ净利润 | **窗口总额比 ≥ 100%**（比 S/A 更严：周期股利润是纸面周期，现金流才是真的；必须用总额比而非逐年比率均值，避免亏损年负净利扭曲） |
| 资本开支 / 营收 | 周期均值 < 10%，且单年扩张峰 ≤ 20% |
| 资产负债率 | < 60%（周期顶部必须留余地） |
| 营收 | 窗口内最大单年跌幅 > -50%（需求不断崖即可） |
| 净利润 | 窗口内亏损年 ≤ 1 个 |
| 分红 | 窗口内有分红记录（亏损年不分红不扣分） |

行业地位要求改表述：周期股的"老大"是**成本地位**——须举证成本位于行业成本曲线最左端或前二（如吨成本、现金成本分位）。**M7 豁免不适用 B 档**（增长本来就不作要求）。

### 降档与判定规则

- 第 0 道一票否决先于一切档位。
- 判定顺序 S → A → B 自动逐档进行，**取最高通过档**作为门禁结论：`通过（S档/A档/B档）`；三档全 FAIL = `否决于第 1 道门`。
- **B 档仅对人工确认的强周期行业标的启用**（`gate_screen.py --cyclical`）；非周期标的 S/A 不过即否决——均值口径不是放松通道，防止消费股借周期均值"混进"B 档（消费股没有周期均值回归逻辑，其下滑往往是结构性的）。
- REVIEW / INSUFFICIENT 不改变档位结论，但必须在报告中列明。

### 档位对后续门的强制联动

- **第 2 道代理硬闸**：S/A 档照旧；B 档 ROIC 改用周期均值 > 8%，"毛利率显著高于同行"改举证"成本位于行业成本曲线左端"。
- **第 2.5 道**：受众映射表照旧；B 档最高只能落"受众收缩但集中度提升"行（g1 ≤5% / g2 ≤2% / gterm ≤1%，再被第 2.6 道归零）。
- **第 2.6 道**：B 档终点判断最高"相当"，**gterm 强制 = 0**。
- **第 3 道**：S/A 档常规 DCF；**B 档强制三口径**（保守 / 中枢 / 乐观），base = 周期中值股东盈余（窗口均值），买入线 = 中枢 IV × 0.65，重仓线 = 保守 IV × 0.65。

**垄断+提价型豁免（M7，增长质量关）**：营收/净利增长门槛 FAIL 时，若标的具备垄断性护城河（国家保密品种 / 独家牌照 / 寡头格局）且量价拆分证明增长为"价驱动"（提价后量不跌，弹性 > -1），允许豁免"营收连续 3 年 >10%"硬门槛，改用**同口径增速 5–8% + 第 2.6 道十年后推断背书**；净利门槛必须用**扣非口径**复核（剔除一次性收益年份）。豁免须在结论中标注 `(M7豁免: 价驱动增长, 依据XXX)`，无豁免标注的增长 FAIL 一律按否决处理。详见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M7。

## 第 2 道 · 护城河定性关（代理硬闸 + LLM 陪审团）

**先用财务代理做硬闸**，任一不过关即否决：毛利率显著高于同行且 5 年不下滑；ROIC 长期 > 10%；合同负债/营收 高；商誉/净资产低；大股东质押率低、无频繁减持；分红回购记录真实。

**硬闸通过后，LLM 做定性陪审**，回答四个问题并强制证据链。详见 [references/qualitative-jury.md](references/qualitative-jury.md)。输出必须结构化为五段：`护城河类型 / 提价权证据 / 文化信号 / 十年后形态 / 否决理由`。每个结论必须引用年报原文或具体数据；证据不足一律判"不通过"。**量价拆分先校验计量单位可比性（规格 / 粒数 / 包装变化须换算统一单位，见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M2）。**

## 第 2.5 道 · 永续性测试（受众推断，business 优先）

**核心规则：永续性无法通过指标衡量，只能通过 business 推断。** 财务指标只能描述过去的需求，受众（买的人）才决定未来的需求。因此本门的裁判顺序是：先答受众两问，财务代理只做辅助证伪——财务代理全 PASS 不能赦免受众恶化，受众强劲也不能赦免财务失血。

**受众两问（必须引用客观数据回答，禁止裸断言）：**

1. **行业受众是谁？** 什么人在买、为什么买（成瘾/必需/场景/社交）、核心人群的人口学画像
2. **未来 10 年受众怎么变？** 核心人群规模增减（人口队列数据）、偏好迁移（代际更替）、替代品威胁——用统计局、行业协会、权威研究报告的数字说话

**受众结论 → 估值假设的强制映射：**

| 受众轨迹 | 永续性结论 | g1（1-5年） | g2（6-10年） | gterm |
|---|---|---|---|---|
| 受众扩张（如老龄化赛道） | 强 | 上限 10% | ≤g1 | ≤3% |
| 受众稳定 | 中 | ≤GDP 名义增速 | ≤g1 | ≤2% |
| 受众收缩但集中度提升（须举证：龙头份额/产量逆势数据） | 中偏弱 | ≤5% | ≤2% | ≤1% |
| 受众收缩且无集中度证据 | 弱 | 终止分析或 g2≤0 | ≤0 | 0 |

完整框架与行业受众数据库见 [references/audience-analysis.md](references/audience-analysis.md)。

**财务代理（辅助证伪，gate_screen.py 自动计算，全用可得数据的全部年份）：**

| 代理指标 | 逻辑 | 门槛（PASS / REVIEW / FAIL） |
|---|---|---|
| 毛利率变异系数 CV | 盈利结构的时间稳定性，护城河不蚀的证据 | ≤0.08 / 0.08–0.15 / >0.15 |
| 营收最大单年跌幅 | 需求是否断过崖 | >-10% / -10%~-30% / ≤-30% |
| 维持性再投入强度 (资本开支+研发)/营收 近 3 年均值 | 巴菲特"变化慢的行业"：不需持续大额投入才能保住地位的公司才配谈永续 | ≤10% / 10–15% / >15% |

## 第 2.55 道 · 叙事推断（叙事先行，永续性第一输入）

**叙事先行：先讲故事，再验数据。** 数据描述"是什么"，叙事推断"意味着什么"。二者不是平行关系，而是**顺序关系**——第 2.6 道十年后推断必须先从叙事链出发（用常识把已核验事实串成讲得通的十年故事），再用数据/指标逐环证伪。**故事讲不通 = 没看懂 = 否决；故事讲得通，数据只负责修正故事，不能取代故事。**

- **为什么永续性本质上是叙事判断**：永续性不是可观测指标，是对"10 年后还活得好不好"的推断。指标只能描述过去，回答不了"惯性会不会持续"——"老龄化不可逆"是常识叙事，"独家品种提价权持续"是常识叙事，"品牌复利后置"是常识叙事。**永续性的强弱 = 常识叙事链的强弱**。叙事先行，指标后验。
- **执行协议（叙事先行四步）**：① 先建叙事链——用常识回答"10 年后这家公司长什么样"（故事先行，故意先不看财务指标）；② N1–N3 校验——每环有已核验事实锚点？环间连接仅凭常识成立？无"下一个 X"类比偷懒？；③ 数字落地——叙事链导出第 2.6 道五要素（量/价/利润率/再投资/终局）与 g 取档；④ 数据证伪——受众数据与财务代理反向校验故事，矛盾时数据优先，但**数据不能单独生成故事**
- **合法性三问（N1–N3）**：链条每一环都有已核验事实锚点？环间连接仅凭常识即可成立（无专业假设）？没有"下一个 X"类比偷懒？
- **加权规则**：事实骨架全 + 常识因果全通 → 结论可从中性升"偏强"；有骨架但 ≥1 环靠专业假设 → 权重不变、标"待验证"；类比 / 链条断裂 / 人群口径错位 → 权重下调或否决该叙事
- **边界**：叙事只能在第 2.5 道映射表的合法区间内取档，不能突破上限；叙事结论进入报告必须标注 `（叙事推断）`，与 `（事实）` 分离；强判断词哨兵（M6）对叙事同样生效
- **因果链审核（叙事审核生死环，强制）**：每条叙事条目必须①基于事实（锚点）②经得起常识推断（连接）③尊重因果链（闭合），三者缺一即非法；审核双向进行——**证实**（每环有支持性证据）与**证伪**（任一环矛盾则数据优先、故事重写）；且**否定叙事同样须有事实锚点**——"十年后不可预测"式无锚点否定与"下一个 X"式无锚点肯定是同罪，凡写"看不懂/不可预测"必须指出断环处及其事实依据。周期股禁止用"价不可预测"跳过建链：价的波动不可锚定 ≠ 受众/量不可锚定（慢变量：能源结构/人口队列/行业集中度），先做受众推断再决定可否决。详见 [references/narrative-inference.md](references/narrative-inference.md) 二点六
- 完整框架与叙事先行协议见 [references/narrative-inference.md](references/narrative-inference.md)

## 第 2.6 道 · 十年后经营推断（估值假设的唯一合法来源）

受众推断回答"还有多少人买"，本门回答"**10 年后这家公司长什么样**"。dcf.py 的 g1/g2 不得凭空设定，必须从本推断中导出；推断写不出来 = 没看懂 = 否决（段永平："10 年后会不错的公司才买"）。**每个 g 必须带溯源码**（受众轨迹映射上限 / 十年后推断量价拆解 / 同口径历史复合增速，三者取最低并写明取舍），无来源假设视为未通过，见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M3。

**推断五要素（逐一落到数字，禁止定性套话）：**

1. **量**：受众轨迹 × 公司份额趋势（份额升/稳/降 + 证据：公司销量 vs 行业销量的 5 年背离度）
2. **价**：提价权是否仍在（出厂价 vs 批价、历史提价后销量反应、毛利率趋势）
3. **利润率**：竞争格局走向决定（垄断加强→稳中有升；内卷加剧→承压），给出 10 年后净利率方向
4. **再投资**：维持地位所需的 capex/研发（扩张期投入在行业收缩时是加分还是自杀？）
5. **终点判断**：10 年后公司比今天**更强 / 相当 / 更弱**——"更强"才可取映射上限，"相当"取中档，"更弱"取 0 并通常应终止

**输出格式（每只标的必填）：**

```
10 年后经营图景：营收 ≈X 亿（量 __% × 价 __% × 份额 __），净利率 __%（方向 __），
股东盈余 ≈Y 亿；终点判断：更强/相当/更弱（依据：……）
导出的估值假设：g1=__%、g2=__%（须 ≤ 第 2.5 道映射上限）
```

框架与首批标的实例见 [references/operating-forecast.md](references/operating-forecast.md)。

## 第 3 道 · 估值关（毛估估）

用股东盈余（净利润 + 折旧摊销 − 维持性资本开支）做 10 年毛估估折现，折现率取投资者机会成本（不低于无风险利率）。只在价格 < 内在价值 × 安全边际（0.6–0.7）时判"通过"。折现是思维方式不是计算器——敢用保守假设把账算清，才算看懂（林园："必须知道多少钱了，我们才会出手"）。**出结论前用 Gordon 反推当前市价隐含增速并与自己的 g 对照，偏离 > 2pp 必须解释（我的假设更对 / 市场定价了我没看见的东西），见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M4。** 详见 [references/valuation.md](references/valuation.md)。

## 输出格式

**数据类结论，明细先行，以便人工审核（强制规则）**：任何涉及数字的结论（硬指标判定、ROE/毛利率/OCF/NP 等比率、增速、估值区间、安全边际）必须**先给出可复核明细，再给结论**——写清口径定义（分子分母取自哪张表哪个字段）、原始数值（单位/亿元）、计算过程（公式 + 代入值）、阈值对比（超/达标多少）。禁止只抛"毛利率 -0.6pp 超容忍""ROE 14.3% < 15%"这类结论性表述而不给计算链路；人工无法复核的结论视为未完成。

每只股票输出：

```
门禁结论：通过（S档/A档/B档）/ 否决于第 N 道门
档位判定明细：（S→A→B 逐档的 PASS/FAIL 项与阈值差）
否决或存疑理由：（具体数据 + 引用，且逐项附明细：口径/原始值/算式/阈值差）
四道门逐项检查结果表
当前股价：____（报价币种 + 日期，必要时换算报告币种并标注汇率）
估算中枢股价：____（毛估估每股内在价值中枢；否决标的同样必填，标注"参考值——否决后不作买入依据"）
（若通过）内在价值毛估估区间 与 当前价格的安全边际
```

**当前股价与估算中枢股价为全标的强制输出项（含被否决标的）**：当前股价取自最新行情快照（`listings[].last_close`，注明币种与日期，折算报告币种用 `fx_to_report_currency`）；估算中枢股价用 `tools/dcf.py` 按保守假设（g 取第 2.55 道叙事推断档位下限或更保守）计算每股内在价值中枢。**被否决标的不因否决而豁免估值输出**——参考中枢供人工对照"现价距中枢多远"，帮助区分"便宜但坏"（价格 < 中枢仍否决）与"贵且坏"；但否决标的的估值一律标注"参考值——否决后不作买入依据"，不得作为买入信号。
