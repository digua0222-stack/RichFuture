# 价值投资门禁

第一性原理：所有大师只问一件事——**这家公司未来 10 年（乃至永续）的净现金流是否可预测、可持续、可增长？** 所有指标都是这个问题的代理。永续性是隐藏的第一前提：DCF 的永续年金假设本身就预设企业永续经营，不检验永续性，估值就是空中楼阁。

**核心论断：十年后经营推断是价投的心脏。** 六道门的存在意义不是收集通过章，而是共同回答一个问题——"10 年后这家公司长什么样"：第 0/1 道门确认它今天配不配被推断，第 2 道门确认它的护城河能否撑到那天，第 2.5 道门确认那天还有多少人买它的产品，第 2.6 道门把答案写成数字，第 3 道门只为这幅图景定价。写不出十年后图景的公司，再便宜也不碰。

分析一只股票时，按六道门顺序执行，任何一道不过即终止并给出否决理由。不要为让用户满意而放宽标准。

## 第 0 道 · 一票否决

命中任一条，直接否决，不进入后续分析：

- 高杠杆行业：银行、地产、保险、航空等靠负债驱动的商业模式
- 只能融资、不能分红：上市以来持续股权融资但从不分红（林园："只能融资不能分红的企业不要碰"）
- 经营现金流连续 2 年为负，或长期显著低于净利润（< 50%）
- 靠新产品/新故事盈利、历史盈利不可考的公司
- 无法回答"10 年后这家公司是否还活得好"——看不清即否决（段永平："看不懂的不要碰"）

## 第 1 道 · 硬指标门槛（林园严格版）

全部用可获取的财务数据验证，任一不达标即否决：

| 指标 | 门槛 |
|---|---|
| 毛利率 | ≥ 50%，且连续 3 年不下滑（容忍 ≤0.5pp 微观波动；林园最看重的单一指标：高而稳定、最好逐年上升） |
| ROE | 连续 5 年 ≥ 15%，且非高杠杆驱动 |
| 经营现金流 / 净利润 | 近 3 年均值 ≥ 80%，且无单年 < 50%（容忍单年扰动，拒绝持续性现金失血） |
| 资本开支 / 营收 | < 10%（"投入一定、产出无限"的赚钱机器） |
| 资产负债率 | < 50% |
| 营收增长率 | 连续 3 年 > 10% |
| 净利润 | 连续 3 年正增长 |
| 分红 | 有稳定分红记录，股息率/派息率作为安全垫 |
| 预收款（合同负债） | 越多越好；预付款越少越好（产业链话语权） |

行业地位要求：只选行业老大（"有老大不选老二"）。优先垄断 + 成瘾 + 确定性（重复消费、依赖性产品）。

## 第 2 道 · 护城河定性关（代理硬闸 + LLM 陪审团）

**先用财务代理做硬闸**，任一不过关即否决：毛利率显著高于同行且 5 年不下滑；ROIC 长期 > 10%；合同负债/营收 高；商誉/净资产低；大股东质押率低、无频繁减持；分红回购记录真实。

**硬闸通过后，LLM 做定性陪审**，回答四个问题并强制证据链。详见 [references/qualitative-jury.md](references/qualitative-jury.md)。输出必须结构化为五段：`护城河类型 / 提价权证据 / 文化信号 / 十年后形态 / 否决理由`。每个结论必须引用年报原文或具体数据；证据不足一律判"不通过"。**量价拆分先校验计量单位可比性（规格 / 粒数 / 包装变化须换算统一单位，见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M2）。**

## 第 2.5 道 · 永续性测试（受众推断，business 优先）

**核心规则：永续性无法通过指标衡量，只能通过 business 推断。** 财务指标只能描述过去的需求，受众（买的人）才决定未来的需求。因此本门的裁判顺序是：先答受众两问，财务代理只做辅助证伪——财务代理全 PASS 不能赦免受众恶化，受众强劲也不能赦免财务失血。

**受众两问（必须引用客观数据回答，禁止裸断言）：**

1. **行业受众是谁？** 什么人在买、为什么买（成瘾/必需/场景/社交）、核心人群的人口学画像
2. **未来 10 年受众怎么变？** 核心人群规模增减（人口队列数据）、偏好迁移（代际更替）、替代品威胁——用统计局、行业协会、权威研究报告的数字说话

**受众结论 → 估值假设的强制映射：**

| 受众轨迹 | 永续性结论 | g1（1-5年） | g2（6-10年） | gterm |
|---|---|---|---|---|
| 受众扩张（如老龄化赛道） | 强 | 上限 10% | ≤g1 | ≤3% |
| 受众稳定 | 中 | ≤GDP 名义增速 | ≤g1 | ≤2% |
| 受众收缩但集中度提升（须举证：龙头份额/产量逆势数据） | 中偏弱 | ≤5% | ≤2% | ≤1% |
| 受众收缩且无集中度证据 | 弱 | 终止分析或 g2≤0 | ≤0 | 0 |

完整框架与行业受众数据库见 [references/audience-analysis.md](references/audience-analysis.md)。

**财务代理（辅助证伪，gate_screen.py 自动计算，全用可得数据的全部年份）：**

| 代理指标 | 逻辑 | 门槛（PASS / REVIEW / FAIL） |
|---|---|---|
| 毛利率变异系数 CV | 盈利结构的时间稳定性，护城河不蚀的证据 | ≤0.08 / 0.08–0.15 / >0.15 |
| 营收最大单年跌幅 | 需求是否断过崖 | >-10% / -10%~-30% / ≤-30% |
| 维持性再投入强度 (资本开支+研发)/营收 近 3 年均值 | 巴菲特"变化慢的行业"：不需持续大额投入才能保住地位的公司才配谈永续 | ≤10% / 10–15% / >15% |

## 第 2.55 道 · 叙事推断（跨门平行，权重调节器）

数据描述"是什么"，叙事推断"意味着什么"。**叙事不是事实证据**，是用常识把已核验事实串成因果链的推断；它不能证明任何事，但符合常识的叙事可以**提高对应结论的权重**（如老龄化不可逆 → 提价权持续性的加权）。两者缺一不可：只信数据漏掉结构性慢变量，只信叙事掉进故事陷阱。

- **合法性三问（N1–N3）**：链条每一环都有已核验事实锚点？环间连接仅凭常识即可成立（无专业假设）？没有"下一个 X"类比偷懒？
- **加权规则**：事实骨架全 + 常识因果全通 → 结论可从中性升"偏强"；有骨架但 ≥1 环靠专业假设 → 权重不变、标"待验证"；类比 / 链条断裂 / 人群口径错位 → 权重下调或否决该叙事
- **边界**：叙事只能在第 2.5 道映射表的合法区间内取档，不能突破上限；叙事结论进入报告必须标注 `（叙事推断）`，与 `（事实）` 分离；强判断词哨兵（M6）对叙事同样生效
- 完整框架与达仁堂实证见 [references/narrative-inference.md](references/narrative-inference.md)

## 第 2.6 道 · 十年后经营推断（估值假设的唯一合法来源）

受众推断回答"还有多少人买"，本门回答"**10 年后这家公司长什么样**"。dcf.py 的 g1/g2 不得凭空设定，必须从本推断中导出；推断写不出来 = 没看懂 = 否决（段永平："10 年后会不错的公司才买"）。**每个 g 必须带溯源码**（受众轨迹映射上限 / 十年后推断量价拆解 / 同口径历史复合增速，三者取最低并写明取舍），无来源假设视为未通过，见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M3。

**推断五要素（逐一落到数字，禁止定性套话）：**

1. **量**：受众轨迹 × 公司份额趋势（份额升/稳/降 + 证据：公司销量 vs 行业销量的 5 年背离度）
2. **价**：提价权是否仍在（出厂价 vs 批价、历史提价后销量反应、毛利率趋势）
3. **利润率**：竞争格局走向决定（垄断加强→稳中有升；内卷加剧→承压），给出 10 年后净利率方向
4. **再投资**：维持地位所需的 capex/研发（扩张期投入在行业收缩时是加分还是自杀？）
5. **终点判断**：10 年后公司比今天**更强 / 相当 / 更弱**——"更强"才可取映射上限，"相当"取中档，"更弱"取 0 并通常应终止

**输出格式（每只标的必填）：**

```
10 年后经营图景：营收 ≈X 亿（量 __% × 价 __% × 份额 __），净利率 __%（方向 __），
股东盈余 ≈Y 亿；终点判断：更强/相当/更弱（依据：……）
导出的估值假设：g1=__%、g2=__%（须 ≤ 第 2.5 道映射上限）
```

框架与首批标的实例见 [references/operating-forecast.md](references/operating-forecast.md)。

## 第 3 道 · 估值关（毛估估）

用股东盈余（净利润 + 折旧摊销 − 维持性资本开支）做 10 年毛估估折现，折现率取投资者机会成本（不低于无风险利率）。只在价格 < 内在价值 × 安全边际（0.6–0.7）时判"通过"。折现是思维方式不是计算器——敢用保守假设把账算清，才算看懂（林园："必须知道多少钱了，我们才会出手"）。**出结论前用 Gordon 反推当前市价隐含增速并与自己的 g 对照，偏离 > 2pp 必须解释（我的假设更对 / 市场定价了我没看见的东西），见 [references/anti-misjudgment.md](references/anti-misjudgment.md) M4。** 详见 [references/valuation.md](references/valuation.md)。

## 输出格式

每只股票输出：

```
门禁结论：通过 / 否决于第 N 道门
否决或存疑理由：（具体数据 + 引用）
四道门逐项检查结果表
（若通过）内在价值毛估估区间 与 当前价格的安全边际
```
